# PixelChibiAvatarEngine Identity Preservation Rules


## Purpose

This file defines how to preserve the identity of the person in the uploaded photo.

The generated pixel character must represent the same person.

Pixel simplification is allowed.

Identity replacement is forbidden.


---

# Identity Priority
---

# Identity Lock Enhancement v1.1


## Core Requirement


The pixel character must preserve the strongest recognizable features of the uploaded person.


The output should feel like:


"the same person drawn as a pixel chibi"


not:


"a cute pixel character inspired by the person"



---

# Facial Identity Priority


When simplifying the face into pixel art:


Preserve these features first:


## Eyes


Eyes are the strongest identity signal.


Analyze:


- eye shape
- eye size
- eye angle
- eyelid shape
- eye spacing
- gaze direction


Do not replace with a universal anime eye style.


Different people must have different pixel eyes.



---

## Face Shape


Maintain:


- face width
- chin shape
- cheek proportion
- overall facial silhouette


The face can be simplified.

The identity cannot be simplified away.



---

## Expression


The original expression must remain.


Examples:


Photo:

gentle smile


Pixel:

gentle smile


Photo:

neutral expression


Pixel:

neutral expression


Do not automatically make every character:

- smiling
- cute
- happy



---

# Hair Identity Enhancement


Hair silhouette is a major identity feature.


Preserve:


- overall hair shape
- hair volume
- hair direction
- bangs
- hair accessories


The hairstyle should be recognizable from a silhouette.


---

# Anti-Template Face Rule


Avoid creating the same face for every character.


Do not use:


- identical round eyes
- identical mouth
- identical face shape


Each generated character must inherit facial differences from the uploaded image.



---

# Identity Verification v1.1


Before output:


Ask:


1. If the original photo disappeared, would this still feel like the same person?

2. Are the eyes unique to this person?

3. Is the hairstyle immediately recognizable?

4. Is the expression preserved?


If no:

increase identity preservation.

The following features are the most important:


## 1. Hair Identity ⭐⭐⭐⭐⭐


Hair is one of the strongest recognition features.


Preserve:

- hair length
- hair volume
- hair color
- hairstyle
- bangs shape
- parting direction
- curls or straightness
- tied or untied hair
- special hair accessories


Examples:


Long wavy hair:

Keep large flowing hair silhouette.


Straight long hair:

Keep smooth vertical hair shape.


Hat:

Keep hat shape and position.


Do not:

- replace hairstyle
- shorten hair
- create random anime hairstyle


---

# 2. Face Shape ⭐⭐⭐⭐


Maintain:

- overall face silhouette
- face width
- chin shape
- cheek shape


Pixel style may simplify:

- skin details
- tiny facial lines


But must keep:

- recognizable face structure


---

# 3. Eye Characteristics ⭐⭐⭐⭐⭐


Eyes are critical identity features.


Analyze:

- eye size
- eye shape
- eye angle
- eye distance
- eyelid expression
- open/closed eye state


Examples:


Person winking:

Pixel character keeps wink.


Person with smiling eyes:

Pixel character keeps smiling eyes.


Person looking sideways:

Pixel character keeps gaze direction.


Do not:

- create identical round anime eyes for everyone
- remove expression


---

# 4. Eyebrows


Preserve:

- eyebrow thickness
- eyebrow angle
- eyebrow visibility


Eyebrows affect expression.


---

# 5. Mouth Expression


Preserve:

- smile
- neutral expression
- open mouth
- lip shape impression


Convert into simple pixel expression.


Do not:

- force a smile
- force a cute expression


---

# 6. Unique Features


Keep recognizable details:


Examples:

- glasses
- earrings
- freckles
- hair clips
- hats
- jewelry
- special makeup


---

# Pixel Face Conversion Rules


The face should become:


Large chibi head

+

simple pixel features

+

recognizable identity


Recommended:

- expressive eyes
- small mouth
- soft shading
- clear silhouette


Avoid:

- realistic face rendering
- detailed human portrait
- generic anime face


---

# Identity Verification


Before final output check:


✓ Same hairstyle?

✓ Same hair color?

✓ Same face feeling?

✓ Same eye expression?

✓ Same mouth expression?

✓ Same accessories?


If identity is lost:

Increase photo feature preservation.

Do not increase random artistic creativity.
