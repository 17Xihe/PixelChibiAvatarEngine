# PixelChibiAvatarEngine Identity Preservation Rules


## Purpose

This file defines how to preserve the identity of the person in the uploaded photo.

The generated pixel character must represent the same person.

Pixel simplification is allowed.

Identity replacement is forbidden.


---

# Identity Priority


The following features are the most important:


## 1. Hair Identity ⭐⭐⭐⭐⭐


Hair is one of the strongest recognition features.


Preserve:

- hair length
- hair volume
- hair color
- hairstyle
- bangs shape
- parting direction
- curls or straightness
- tied or untied hair
- special hair accessories


Examples:


Long wavy hair:

Keep large flowing hair silhouette.


Straight long hair:

Keep smooth vertical hair shape.


Hat:

Keep hat shape and position.


Do not:

- replace hairstyle
- shorten hair
- create random anime hairstyle


---

# 2. Face Shape ⭐⭐⭐⭐


Maintain:

- overall face silhouette
- face width
- chin shape
- cheek shape


Pixel style may simplify:

- skin details
- tiny facial lines


But must keep:

- recognizable face structure


---

# 3. Eye Characteristics ⭐⭐⭐⭐⭐


Eyes are critical identity features.


Analyze:

- eye size
- eye shape
- eye angle
- eye distance
- eyelid expression
- open/closed eye state


Examples:


Person winking:

Pixel character keeps wink.


Person with smiling eyes:

Pixel character keeps smiling eyes.


Person looking sideways:

Pixel character keeps gaze direction.


Do not:

- create identical round anime eyes for everyone
- remove expression


---

# 4. Eyebrows


Preserve:

- eyebrow thickness
- eyebrow angle
- eyebrow visibility


Eyebrows affect expression.


---

# 5. Mouth Expression


Preserve:

- smile
- neutral expression
- open mouth
- lip shape impression


Convert into simple pixel expression.


Do not:

- force a smile
- force a cute expression


---

# 6. Unique Features


Keep recognizable details:


Examples:

- glasses
- earrings
- freckles
- hair clips
- hats
- jewelry
- special makeup


---

# Pixel Face Conversion Rules


The face should become:


Large chibi head

+

simple pixel features

+

recognizable identity


Recommended:

- expressive eyes
- small mouth
- soft shading
- clear silhouette


Avoid:

- realistic face rendering
- detailed human portrait
- generic anime face


---

# Identity Verification


Before final output check:


✓ Same hairstyle?

✓ Same hair color?

✓ Same face feeling?

✓ Same eye expression?

✓ Same mouth expression?

✓ Same accessories?


If identity is lost:

Increase photo feature preservation.

Do not increase random artistic creativity.
