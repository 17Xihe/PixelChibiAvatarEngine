# PixelChibiAvatarEngine Negative Rules
# Anti Beauty Face Rules


Avoid:


- realistic beautiful face
- mature woman appearance
- fashion model face
- sharp facial structure
- realistic lips
- detailed makeup
- seductive expression


The character should look:

cute and adorable,

not:

beautiful and realistic.

## Purpose

This file prevents common generation failures.

Negative rules should protect identity and style.

They should not remove important photo details.


---

# Character Generation Errors


Avoid:


## 1. Generic Character Generation


Do not create:

- random pixel character
- unrelated person
- default game avatar
- template NPC


The output must come from the uploaded photo.


---

## 2. Identity Loss


Avoid losing:


- hairstyle
- face characteristics
- eye expression
- clothing identity
- accessories


Do not replace the person with:

- generic anime face
- identical cute face
- random character design


---

## 3. Pose Loss


Avoid:


- default standing pose
- symmetrical idle pose
- straight front-facing character


Do not change:


- hand gestures
- body direction
- movement


---

## 4. Clothing Redesign


Avoid:


- changing outfit
- removing accessories
- replacing clothing style
- inventing new fashion


The clothing should remain recognizable.


---

## 5. Wrong Visual Style


Avoid:


- realistic human portrait
- photo rendering
- 3D character
- smooth digital painting
- cartoon illustration without pixels
- Minecraft style
- low-quality pixel blobs


---

## 6. Pixel Quality Problems


Avoid:


- blurry pixels
- noisy pixels
- random pixel placement
- broken silhouette
- unclear character shape


---

## 7. Anatomy Problems


Avoid:


- extra fingers
- extra arms
- missing limbs
- distorted body connections
- unnatural hands


Hands can be simplified.

Correct structure is more important than detail.


---

## 8. Expression Problems


Avoid:


- emotionless face
- changing expression
- forced smile
- exaggerated anime expression


Keep the original expression.


---

# Important Balance Rule


Do not simplify away:


- identity
- pose
- clothing
- accessories


Simplify only:


- tiny textures
- unnecessary details
- realistic surface information


---

# Final Negative Check


Before output:


Reject results that:


✗ look like a generic NPC

✗ could belong to anyone

✗ lose the original pose

✗ lose the original outfit

✗ lose the person's identity


The final character must feel like:

"The same person transformed into pixel art."
