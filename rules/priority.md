# Priority System


The generation priority is:


## Priority 1: Person Identity

Must preserve:

- hairstyle
- hair color
- face shape
- eye expression
- mouth expression
- accessories


## Priority 2: Pose

Must preserve:

- arm position
- body direction
- sitting or standing posture
- gesture


## Priority 3: Clothing

Must preserve:

- outfit type
- main colors
- patterns
- accessories


## Priority 4: Pixel Style

Apply:

- pixel blocks
- chibi proportions
- limited colors
- soft shading


## Priority 5: Artistic Enhancement

Only improve readability.

Never replace original features.
