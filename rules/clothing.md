# PixelChibiAvatarEngine Clothing Preservation Rules


## Purpose

This file controls clothing transformation.

The generated pixel character must preserve the person's original outfit.

Clothing should be simplified into pixel art.

It should not be redesigned.


---

# Clothing Priority


Preserve:


- overall clothing silhouette
- main colors
- clothing type
- important patterns
- accessories
- unique details


The outfit should remain recognizable.


---

# 1. Clothing Silhouette ⭐⭐⭐⭐⭐


Analyze:


- top shape
- sleeve length
- collar shape
- jacket/coat structure
- skirt or pants shape
- loose or fitted style


Examples:


Oversized hoodie:

Keep oversized silhouette.


Long dress:

Keep long dress shape.


Short skirt:

Keep short skirt proportion.


Do not:

Replace clothing with generic outfits.


---

# 2. Color Preservation ⭐⭐⭐⭐⭐


Keep:


- main clothing colors
- secondary colors
- color contrast
- important color blocks


Pixel conversion:


Convert colors into:


- base color
- shadow color
- highlight color


Do not:

- randomly change clothing colors
- simplify everything into one color


---

# 3. Pattern Preservation ⭐⭐⭐⭐


Important patterns should remain.


Examples:


- logos
- stripes
- flowers
- text-like graphics
- prints
- decorative elements


Simplify patterns into readable pixel shapes.


Do not:

Remove recognizable patterns.


---

# 4. Accessories ⭐⭐⭐⭐⭐


Preserve:


- hats
- glasses
- earrings
- necklaces
- bags
- hair accessories
- watches


Accessories are identity features.


Do not:

Remove small but important items.


---

# 5. Layered Clothing


Maintain clothing layers.


Examples:


Photo:

Jacket + inner shirt.


Pixel:

Keep jacket layer and inner layer.


Photo:

Sweater + skirt.


Pixel:

Keep both.


Do not merge all clothing into one simple shape.


---

# 6. Pixel Conversion Method


Convert clothing into:


- clear pixel blocks
- simple shading
- readable silhouette


Use:


base color

+

shadow blocks

+

highlight pixels


Avoid:


- realistic fabric texture
- 3D rendering
- smooth gradients


---

# Forbidden Clothing Changes


Never:


- create random fashion style
- replace outfit
- remove major clothing items
- change clothing category
- ignore accessories


Examples:


Photo:

Black hoodie.


Wrong:

White shirt.


Photo:

Dress.


Wrong:

T-shirt and pants.


Photo:

Hat.


Wrong:

No hat.


---

# Clothing Verification


Before output:


Check:


✓ Same outfit type?

✓ Same main colors?

✓ Same important patterns?

✓ Same accessories?

✓ Same clothing silhouette?


If clothing identity is lost:

Restore original outfit details.
