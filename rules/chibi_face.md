# Chibi Face Style Rules


## Goal

Create a cute childlike pixel face.


## Required


- big round eyes
- soft cheeks
- tiny mouth
- simple nose
- innocent expression


## Avoid


- realistic beauty face
- mature female face
- sharp jaw
- detailed makeup
- fashion model appearance


## Style


The face should resemble:

- pixel doll
- game mascot
- cute avatar


Not:

- anime beauty character
- realistic portrait
