# PixelChibiAvatarEngine Style Rules


## Purpose

This file defines the visual style of the generated pixel chibi character.

The output should look like a cute collectible pixel avatar.

The style must enhance the person's identity.

It must not replace the person.


---

# Target Visual Style


The target style is:


Cute pixel chibi character

with:

- large head
- small body
- expressive face
- clean pixel edges
- soft pixel shading
- detailed but simplified clothing


The result should feel like:

a modern pixel character illustration


Not:

a basic game NPC sprite.


---

# Character Proportion


Use chibi proportions.


Recommended:

Head:

approximately 35%-45% of total character height


Body:

approximately 35%-45%


Legs:

approximately 15%-25%


Features:

- oversized head
- short limbs
- small hands and feet
- cute silhouette


Avoid:

realistic human proportions.


---

# Pixel Rendering Style


Use:


- visible pixel blocks
- sharp pixel edges
- controlled pixel clusters
- limited color palette
- layered shading


Pixel appearance should be intentional.


Avoid:


- blurry pixels
- smooth digital painting
- realistic rendering
- 3D style


---

# Color Style


Use:


- main color
- shadow color
- highlight color


Colors should be:


- soft
- harmonious
- slightly warm


Avoid:


- excessive colors
- random color changes
- harsh gradients


---

# Face Style


The face should be:


- simple
- cute
- expressive


Keep:


- eye expression
- mouth expression
- facial characteristics


Use:


- small pixel eyes
- clear expression
- subtle highlights


Avoid:


- realistic human facial details
- generic anime face
- identical faces


---

# Hair Style


Hair should be represented by:


- large pixel shapes
- clear silhouette
- layered color blocks


Include:


- volume
- direction
- hairstyle identity


Avoid:


- thin realistic hair strands
- random hairstyle redesign


---

# Clothing Rendering


Clothing should use:


- clear silhouette
- large color areas
- pixel shading


Preserve:


- outfit identity
- patterns
- accessories


Avoid:


- overly simplified clothing
- generic outfits


---

# Pixel Detail Level


The character should have:


Enough detail to recognize:

- person
- hairstyle
- outfit
- expression


But not:

- realistic texture
- photographic details


Balance:

recognition + pixel charm


---

# Background


Default:

simple clean background.


Recommended:

- white
- transparent
- simple solid color


The character is the focus.


---

# Style Restrictions


Do not create:


- realistic portraits
- 3D cartoon characters
- Disney-like characters
- anime illustration
- Minecraft style
- low-quality pixel blobs
- generic RPG NPCs


---

# Final Style Check


Before output:


✓ Does it look like a cute pixel avatar?

✓ Does it have a large-head chibi proportion?

✓ Are pixels clear?

✓ Is the person still recognizable?

✓ Does it match the reference style?


If not:

increase chibi pixel characteristics without losing identity.
