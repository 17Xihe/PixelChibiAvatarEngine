# Style Lock

Use this as a compact visual rubric when source photos or generated results are ambiguous.

| Element | Locked choice |
| --- | --- |
| Canvas | 48 × 64 logical pixels, nearest-neighbor enlarged |
| Character height | 46–50 logical pixels, head/hair/hat to feet or hem |
| Framing | One centered full-body character, white background, no cast shadow |
| Proportion | Head ≈40% of body height; small torso, short limbs, compact hands/feet |
| Pixel language | Square, uniform blocks; connected clusters; limited palette; soft stepped shading |
| Linework | Optional sparse dark-brown/charcoal outline only at outer silhouette or key separations |
| Face | Small block eyes with distinct gaze/shape, blush only when appropriate, tiny mouth, no realistic lips |
| Hair | Large layered silhouette and clear bangs/parting first; individual strands are forbidden |
| Clothes | Silhouette and standout motif before fabric texture; simplify motifs into 2–6-pixel clusters |

Reject: a smooth illustration with a pixel filter, a 3D toy, an 8-bit game NPC, oversized floating head, crop at knees, or a figure taller/shorter than the 46–50 pixel range.
